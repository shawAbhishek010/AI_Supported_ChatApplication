# AI Study Assistant Frontend

This is the React + Vite frontend for the AI Study Assistant project.

For full project setup, backend startup, database setup, Ollama setup, API details, and troubleshooting, see the root project README:

```text
../../README.md
```

## Start Frontend

Start the backend first, then run:

```powershell
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

The Vite dev server proxies `/api` and `/ws-chat` to the Spring Boot backend at `http://localhost:8080`.
